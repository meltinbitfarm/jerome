# `jerome note`

The notes you sent a project from [Telegram](../telegram.md) (D133).

```sh
jerome note add <text> [--urgent]   # leave the project in this folder a note; urgent: see below
jerome note list [dir]              # the open notes, in full, urgent first
jerome note done <id> [dir]         # close one, once recorded in open.md or decisions.md
```

**Urgent notes** (D216): on Telegram, the **⚡ Urgent** button under the message that says the note was saved, or `!` before the text (`! take the old pages off`); the **Urgent** box under the dashboard's note; here, `--urgent` or `!`. The project gets a run as soon as it can, within a couple of minutes on a Mac the [Director](../director.md) directs: past the week's pace, the reserve kept for you and the areas' pace. Only the 5-hour cap, the project's own limits, a run already going (it waits for its end) and a session you are working in hold it. The triage takes the urgent note as its task and the lead agent does it before anything else. One run per note: once a run of the lead agent has taken it, it is an ordinary open note until the lead agent closes it.

The lead agent closes a note after recording what it means; the project's permission rules allow it `jerome note *`. `jerome state` shows the open ones on a `NOTES` line.
