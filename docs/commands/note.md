# `jerome note`

The notes you sent a project from [Telegram](../telegram.md) (D133).

```sh
jerome note list [dir]        # the open notes, in full
jerome note done <id> [dir]   # close one, once recorded in open.md or decisions.md
```

The lead agent closes a note after recording what it means; the project's permission rules allow it `jerome note *`. `jerome state` shows the open ones on a `NOTES` line.
